# Simulator Route (`/simulator`)

## Purpose
Attack simulator and security test bench for generating synthetic traffic and validating detection capabilities.

## Planned Features
* Attack vector presets (SQL Injection, XSS probe, Path Traversal, Credential Stuffing, DDoS surge)
* Target endpoint selector
* Simulation concurrency and rate sliders
* Real-time validation feed confirming whether API-SENTINEL correctly detected and blocked the attack
