# Next.js App Router (`frontend/app`)

This directory contains the page routes, layouts, and route handlers for the API SENTINEL frontend.

## Routes
* `/dashboard`: Main Security Operations Center (SOC) summary overview.
* `/threats`: Real-time threat feeds, anomaly alerts, and incident investigations.
* `/endpoints`: Monitored API inventory, status checks, and endpoint policies.
* `/requests`: Live API request inspector and audit logs.
* `/policies`: Rate-limiting rules, IP filtering, and mitigation strategies.
* `/simulator`: Attack simulation engine and load scenario runner.
