# UI Components (`frontend/components`)

This directory houses reusable, presentation, and compound UI components for **API SENTINEL**.

## Planned Component Structure
* `ui/`: Primitives such as buttons, badges, inputs, dialogs, and cards.
* `layout/`: Navbar, sidebar navigation, headers, breadcrumbs, and command palettes.
* `charts/`: Visualizations for threat metrics, request latency, volume over time, and geographic heatmaps.
* `threats/`: Threat alert banners, severity score pills, and incident detail panels.
