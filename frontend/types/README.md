# TypeScript Types & Interfaces (`frontend/types`)

This directory contains shared type contracts, DTO interfaces, and security domain models synchronized with the backend.

## Expected Types
* `threat.ts`: Threat events, severity categories, detection rule results, and mitigation actions.
* `endpoint.ts`: Monitored endpoint descriptors, status, latency metrics, and route signatures.
* `policy.ts`: Rate limiting rule schemas, IP block/allow lists, and enforcement triggers.
* `simulation.ts`: Attack scenario configurations, generator options, and simulation run results.
* `user.ts`: User session, authentication tokens, and permissions.
